Один скос — 10px — на всё

Скос это фиксированный бренд-знак, а не сигнал важности. Кнопка, карточка, KPI, hero — у всех одинаковый срез 10px. Иерархия строится цветом и движением, не размером скоса.

Когда: элемент настолько мал, что 10px съедает почти весь угол (крошечные теги, чекбоксы, аватары). Легаси-шкала ch-* 4–28px существует только для этого. Не увеличивай срез для «более важных» блоков — это и есть баг, из-за которого каждый экран выглядит по-разному.
