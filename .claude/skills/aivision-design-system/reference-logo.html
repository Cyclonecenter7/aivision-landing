AIVISION · Logo Reference

Один источник правды для логотипа AIVISION. Чистая chamfer-метка без внешней рамки. Все размеры, варианты, PWA-иконки и готовый HTML для подключения.

До и после

Было

Двойной квадрат: iOS-плашка + наш внешний контур = «коробка в коробке»

Стало

Одна chamfer-форма. iOS даёт свою плашку → внутри только метка.

Варианты лого

Логотип = одна chamfer-форма. Цвет адаптируется к фону. Никакой внешней рамки.

На тёмном
fill: #3F6EE8 (синий)
На светлом
fill: #0A0A0A (чёрный)
На синем
fill: #FFFFFF (белый)
Mono (universal)
fill: currentColor

HTML для подключения

Скопировать в <head> любой страницы — favicon, Apple Touch Icon, manifest для PWA.

<!-- В <head> --> <!-- SVG favicon (масштабируется идеально) --> <link rel="icon" type="image/svg+xml" href="/favicon.svg"> <!-- iOS PWA / Apple Touch Icon (180×180) --> <link rel="apple-touch-icon" href="/apple-touch-icon.png"> <!-- PWA manifest --> <link rel="manifest" href="/manifest.json"> <!-- Theme color (цвет адресной строки на мобильном) --> <meta name="theme-color" content="#3F6EE8"> <!-- Apple PWA: убрать стандартную рамку браузера --> <meta name="apple-mobile-web-app-capable" content="yes"> <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent"> <meta name="apple-mobile-web-app-title" content="AIVISION">

SVG path (исходник)

Одна формула. ViewBox 256×256. Внешний контур chamfer — путь ниже.

<svg width="24" height="24" viewBox="0 0 256 256"> <path d="M 0 0 L 256 0 L 256 208 L 208 256 L 0 256 Z" fill="currentColor"/> </svg>
