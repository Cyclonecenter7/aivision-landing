### 1. Блок кейсов на главной (секция #cases)

**Финальный вариант:** Desktop A — асимметрия 1 большой + 3 маленьких  
**Референс:** `cases-v5.html`

**Структура:**
- Hero-карточка (образование) — на 2 строки слева, sparkline маржи, 3 KPI
- Правая колонка — строительство (верх) + E-commerce + eSIM (низ 1:1)
- Каждая карточка — SVG-паттерн вдохновлённый реальным компонентом дашборда:
  - Образование → 3 KPI-карточки с chamfer + спарклайны (как KpiCard)
  - Строительство → 4 stacked bar (нагрузка/прибыль/себес), 3-й гашеный (как StructureBar)
  - E-commerce → воронка с chamfer-барами убывающей ширины (как Funnel)
  - eSIM → две линии на гриде с crosshair и tooltip (как MainChart)
- Hover: accent-линия слева + opacity паттерна 7% → 13%

**Мобилка:**
- Hero — отдельная карточка с sparkline + stat-pills (3 в ряд)
- Остальные 3 кейса — горизонтальный swipe-ряд по 210px

**Дизайн-система:** AIVISION v1.0 — chamfer везде, 7 цветов, Inter, #0A0A0A фон секции

### 2. Страница кейса: eSIM

**Десктоп:** `case-esim-v3.html`  
**Мобила:** `case-esim-mobile.html`

**Нарратив:**
> Старт бизнеса с нуля за 7 дней. Две гипотезы — два сайта с разным позиционированием, один CRM. Первый клиент до конца недели.

**Структура страницы:**
- Nav sticky + NDA-баннер (жёлтый, «Показатели изменены»)
- Hero: eyebrow + тег + H1 + лид + 4 hero-стата
- Две колонки: левая (контент) + правая sticky (живой дашборд)

**Левая колонка:**
1. Две гипотезы — 2 карточки рядом (Сайт 1: СБП/рубли/Россия | Сайт 2: Крипта/мир)
2. Timeline: День 1 → Дни 2–3 → Дни 4–5 → День 6 (★ первый клиент)
3. Что умеет система (4 action-rows)
4. Результат 3×2 сетка

**Правая колонка — живой дашборд с 3 вкладками:**
- Дашборд: Канал 1 (СБП) vs Канал 2 (Крипта) — 4 KPI каждый со спарклайном, графики выручки по дням
- Воронка: оба канала рядом, chamfer-бары убывающей ширины, конверсия ×17 видна сразу
- Топ: продукты по выручке для обоих каналов

**NDA в дашборде:** цифры реальные но изменены — без квадратов, честная сноска

**Мобила — карусель 3 слайда:**
1. Два канала в одном дашборде (KPI 2×2)
2. Воронка с конверсией обоих каналов
3. Топ продуктов + управление наценками

## Дизайн-система — правила для верстальщика

### Геометрия
```css
/* chamfer снизу-справа — основной паттерн */
clip-path: polygon(0 0, 100% 0, 100% calc(100% - Xpx), calc(100% - Xpx) 100%, 0 100%);
/* Размеры: 4 / 6 / 8 / 10 / 12 / 16 / 20 px */

/* Никаких border-radius на карточках и кнопках */
/* Никаких градиентов, glassmorphism, теней кроме shadow-sm на hover */
```

### Палитра (7 цветов, строго)
```
brand     #3F6EE8   — primary, маржа, CTA
emerald   #10B981   — доход, рост, успех
crimson   #F43F5E   — расход, ошибка, стоп
sun       #FCD34D   — предупреждение, NDA-плашка
slate     #94A3B8   — нейтральный, холодный
indigo    #6366F1   — категориальный
tangerine #FB923C   — категориальный
```

### Темы
```
Dark:  bg #0A0A0A · surface #181818 · surface-alt #222222
       border #2A2A2A · text #FFFFFF · text-sec #A3A3A3
Light: bg #FAFAFA · surface #FFFFFF · border #E8E8E8
```

### Eyebrow (обязателен на каждой секции)
```html
<div style="display:flex;align-items:center;gap:10px;margin-bottom:36px">
  <div style="width:24px;height:2px;background:#3F6EE8"></div>
  <span style="font-size:11px;font-weight:600;letter-spacing:.16em;text-transform:uppercase;color:#A3A3A3">ТЕКСТ</span>
</div>
```

### Типографика
- Только Inter
- Italic запрещён
- Числа: `font-variant-numeric: tabular-nums`
- Минус: U+2212 `−`, не дефис
- Валюта: `376 185 ₽` с неразрывным пробелом
