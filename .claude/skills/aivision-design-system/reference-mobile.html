AIVISION CRM · Mobile

Мобильная версия CRM. Три ключевых экрана для работы на ходу: Дашборд (KPI+воронка), Заявки (быстрый ответ) и Задачи (план дня).

Внизу — scrollable tab bar. Видны 3 активных таба, остальные скроллятся свайпом влево. Это позволяет иметь больше 4–5 разделов без burger-меню.

Свайпы:

  • По tab bar — переключение разделов
  • По карточкам заявок — быстрые действия
  • Pull-to-refresh на каждом экране

Открой DevTools → device toolbar для тестирования touch.
