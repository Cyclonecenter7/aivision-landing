Дни 4–5
CRM под оба канала
Один дашборд для двух сайтов. Выручка, маржа, заказы и воронка по каждому каналу отдельно — и сравнение рядом. Наценки и курс управляются из одного интерфейса.

День 6

Что умеет система
01
Единый дашборд двух каналов
Оба сайта в одном интерфейсе. Выручка по каждому, маржа, количество заказов и конверсия — с возможностью сравнения.
02
Воронка от визита до eSIM-кода
Уники → посещения → клики по каталогу → создан заказ → оплачен → выполнен. Видно где теряются клиенты в каждом канале.
03
Управление наценками и курсом
Разные наценки для каждого партнёра, курс конвертации для единого сравнения метрик в рублях. Меняется в один клик.
04
Трекинг источников заказов
По каждому заказу: страна, продукт, цена, маржа, UTM-источник, referrer, landing page. Понятно откуда пришёл клиент.
